# 🖼️ Text-to-Image Generator using API

A simple yet powerful web application that converts text prompts into stunning images using the ClipDrop API. This project demonstrates the integration of front-end technologies with a Python Flask back-end to build an AI-powered text-to-image generator.

## 🚀 Features

- Generate images from text using AI
- Clean and responsive web UI
- Asynchronous image generation with loading animation
- Error handling for invalid or empty prompts
- Built with Flask, HTML, CSS, JavaScript, and ClipDrop API

## 🛠️ Technologies Used

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Python, Flask
- **API**: [ClipDrop Text-to-Image API](https://clipdrop.co/apis/text-to-image)
- **Deployment Ready**: Easily deployable to platforms like Render, Vercel, or Heroku

## 🧑‍💻 How It Works

1. User enters a prompt describing the desired image.
2. Flask sends the prompt to the ClipDrop API.
3. The API generates an image and returns the image URL.
4. The app displays the image in real time.
